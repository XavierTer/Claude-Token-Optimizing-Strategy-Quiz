# Token Optimizer Quiz
A Flask-based web application that provides interactive lessons and quizzes about token optimization.

## Features
- **Interactive Lessons**: Read through 4 lessons about token optimization.
- **Quizzes**: Test your knowledge with 5 quiz questions.
- **Instant Feedback**: Get immediate feedback on your quiz answers, including correct options and explanations.
- **Session Tracking**: The app uses Flask sessions to track your progress and score.

## Project Structure
- `app.py`: The main Flask application file handling routes and logic.
- `data.py`: Contains the lesson content and quiz questions data.
- `requirements.txt`: Lists the Python dependencies required to run the app.
- `templates/`: Directory containing the HTML templates (`home.html`, `learn.html`, `quiz.html`, `results.html`).
- `static/`: Directory containing static assets like CSS and JavaScript files.
